# 예시 채우기 제거 및 일 최대요금 표시 설계

## 목표

방문 계획 입력 카드에서 `예시 채우기` 기능을 제거하고, 주차장 요금 데이터에 일 최대요금이 있을 때 예상요금 상세에 이를 표시한다.

## 예시 채우기 제거

- 입력 카드 헤더의 `예시 채우기` 버튼을 렌더링하지 않는다.
- production `AppShell`에서 버튼 전용 demo handler와 demo 장소 상수를 제거한다.
- 버튼을 CSS나 `hidden` 속성으로 감추지 않고 DOM에서 제거한다.
- AppShell 테스트는 `PlaceSearch`의 테스트 대역으로 출발지와 목적지를 선택한다.
- 실제 `PlaceSearch` 동작은 기존 전용 테스트가 계속 검증한다.

## 일 최대요금 표시

- 기존 예상요금과 단위요금 문구는 유지한다.
- `feeRule.dailyMaximumFee`가 유한한 양수이면 단위요금 아래에 `1일 최대 20,000원` 형식으로 표시한다.
- 값이 없거나 `null`, 0, 음수, 비유한 값이면 일 최대요금 줄을 렌더링하지 않는다.
- 일 최대요금은 추가 계산값이 아니라 서울 주차 데이터의 요금 규칙을 그대로 표시한다.
- 무료 주차장은 일 최대요금 줄을 표시하지 않는다.

## 구조

- `lib/utils.ts`에 일 최대요금 표시 문자열을 반환하는 작은 순수 함수를 추가한다.
- `ParkingCard`는 단위요금과 선택적 일 최대요금을 세로로 배치한다.
- 기존 요금 계산 함수와 API normalizer는 변경하지 않는다.

## 검증

- `ParkingCard` 테스트에서 유효한 일 최대요금이 별도 문구로 표시되는지 확인한다.
- 같은 테스트에서 값이 없는 카드에는 일 최대요금 문구가 없음을 확인한다.
- `AppShell` 테스트에서 `예시 채우기` 버튼이 존재하지 않는지 확인한다.
- 테스트 설정용 장소 선택은 production UI에 테스트 전용 API를 추가하지 않고 컴포넌트 mock으로 처리한다.

## 범위 밖

- 시간별 요금 산식 변경
- 일 최대요금 추정 또는 보간
- 사용자 입력으로 예시 데이터를 자동 채우는 대체 UI
- 서울 데이터 원본의 누락 요금 보정
