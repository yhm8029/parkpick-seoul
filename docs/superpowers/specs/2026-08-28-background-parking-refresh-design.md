# 주차 추천 백그라운드 자동 갱신 설계

## 목표

추천 결과 화면이 열린 동안 동일한 검색 조건으로 2분마다 주차장 정보를 다시 조회해 빈자리와 경로 정보를 갱신한다.

## 동작

- 최초 추천 성공 시점부터 2분 주기를 시작한다.
- 결과 화면이 표시되고 조건 편집 중이 아닐 때만 갱신한다.
- 백그라운드 갱신은 버튼 로딩, 결과 제목 포커스 이동, 모바일 보기, 목록 펼침 상태를 변경하지 않는다.
- 현재 선택한 주차장이 새 응답에도 있으면 선택을 유지한다.
- 현재 선택한 주차장이 사라지면 현재 표시 범위의 1순위를 선택한다.
- 브라우저 문서가 숨겨진 동안에는 요청하지 않는다.
- 문서가 다시 보일 때 마지막 성공 조회 후 2분이 지났다면 즉시 한 번 갱신한다.
- 요청 실패·취소·비정상 응답 시 기존 결과를 유지한다.
- 조건 변경, 편집 진입, 결과 제거, 컴포넌트 해제 시 예약과 진행 중인 자동 갱신을 정리한다.

## 구조

- 기존 추천 요청을 수동 제출과 백그라운드 갱신이 공유하는 함수로 분리한다.
- 수동 제출은 기존 로딩·오류·접힘·포커스 동작을 유지한다.
- 백그라운드 모드는 결과 데이터만 교체하며 UI 제어 상태는 보존한다.
- 기존 AbortController와 draft revision 검사를 유지해 오래된 응답이 최신 상태를 덮지 못하게 한다.

## 검증

- 가짜 타이머로 최초 성공 후 2분 전에는 추가 요청이 없고, 2분에 한 번 추가 요청되는지 확인한다.
- 자동 갱신 응답 적용 후 선택 카드와 펼침 상태가 유지되는지 같은 테스트에서 확인한다.

## 범위 밖

- 서버 푸시, WebSocket, SSE
- 서울 주차 포털 자체 갱신 주기 변경
- 사용자가 자동 갱신 간격을 설정하는 UI
- 백그라운드 탭에서 계속 네트워크 요청
