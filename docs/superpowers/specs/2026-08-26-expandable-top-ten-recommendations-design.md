# 최대 10개 추천과 더 보기 설계

## 목적

목적지 주변의 공영·공공시설 부설 주차장을 최대 10개까지 추천한다. 초기 화면은 기존처럼 상위 3개만 간결하게 보여주고, 사용자가 `더 보기`를 선택했을 때 나머지 카드와 지도 마커를 함께 표시한다.

## 추천 데이터 흐름

- `MAX_RECOMMENDATIONS`는 10으로 고정한다.
- AUTO 모드는 목적지 1km 안의 허용 후보를 직선거리 순으로 최대 10개 고정한 뒤 점수를 계산한다.
- MANUAL 모드는 선택 반경 안의 후보를 점수화한 뒤 최대 10개를 반환한다.
- 후보 membership을 고정한 뒤 최대 10개 각각에 NAVER Directions 5를 병렬 호출한다.
- 실제 경로를 받은 동일 후보 집합만 다시 점수화한다. 경로 호출에 실패한 후보는 기존 거리 기반 추정값을 사용하며 추천 전체는 실패시키지 않는다.
- 응답의 `recommendations`는 0~10개이며 순위는 1부터 연속으로 부여한다.

## 화면 동작

- 결과를 새로 받으면 접힌 상태로 초기화하고 1~3위 카드와 지도 마커만 표시한다. 이전 활성 주차장이 새 상위 3개 안에 있을 때만 선택을 유지하며, 4위 이하이거나 사라졌다면 새 1위를 활성화한다.
- 추천이 4개 이상이면 카드 목록 아래에 `추천 N곳 더 보기` 버튼을 표시한다.
- 더 보기를 누르면 4~10위 카드와 동일 순위의 지도 마커를 함께 표시하고 버튼 문구를 `접기`로 바꾼다.
- 사용자가 접거나 `조건 변경`으로 편집에 들어갈 때 현재 선택된 주차장이 4위 이하라면 1위를 활성화한다. 상위 3개 중 하나가 선택돼 있으면 선택을 유지한다. 모든 접힘 진입점은 같은 상태 전환 함수를 사용한다.
- 추천이 3개 이하이면 더 보기 버튼을 렌더링하지 않는다.
- 결과 제목의 영문 eyebrow는 실제 응답 개수에 맞춰 `TOP N RECOMMENDATIONS`로 표시한다.
- 면책 문구는 특정 순위 대신 `다른 순위도 함께 확인하세요`로 변경한다.

## 지도와 경로

- `MapPanel`에는 현재 펼쳐진 개수만큼의 추천만 전달한다.
- 접힌 상태에서는 기존 3개 지도 밀도를 유지한다.
- 펼치면 최대 10개 마커를 표시하고 bounds를 다시 맞춘다.
- 카드 선택 시 해당 추천의 NAVER 경로선을 표시하는 기존 동작을 유지한다.
- 지도 footer의 추천 범위는 현재 표시 개수에 맞춰 `추천 1~N순위`로 표시한다.
- 현재 표시 추천 배열은 결과와 펼침 상태가 바뀔 때만 다시 계산해, 카드 선택만으로 지도 geometry 직렬화와 지도 재구성이 반복되지 않게 한다.

## 비용과 성능

- 추천 1회당 NAVER Directions 호출은 최대 10회다.
- 호출은 병렬이며 후보별 실패 격리를 유지한다.
- 경로 geometry는 후보당 최대 2,500점, 후보 최대 10개, 혼잡 section 후보당 최대 256개로 제한한다. 한 응답은 최대 25,000개 좌표와 2,560개 혼잡 section을 가진다.
- 응답은 계속 `private, no-store`로 제공한다.
- 앱 자체의 분산 rate limit은 이번 범위에 포함하지 않는다. 추천 1회당 최대 10회 호출이라는 운영 리스크를 수용하고 NAVER Cloud 한도·알림으로 사용량을 관리한다.

## 검증

- 도메인 테스트: AUTO와 MANUAL이 최대 10개를 연속 순위로 반환한다.
- 어댑터/API 테스트: 최대 10개 NAVER 경로를 요청하고 동일 후보만 재평가한다.
- 일부 NAVER 경로가 실패해도 해당 후보만 거리 추정으로 남고 나머지는 NAVER 경로를 유지하는지 확인한다.
- 최악 geometry fixture의 직렬화 크기가 2MiB 미만이고 section 상한이 적용되는지 확인한다.
- UI 테스트: 최초 3개와 지도 마커 3개, 더 보기 후 최대 10개, 접기 후 3개를 확인한다.
- 2위 선택은 접기 후 유지되고 10위 선택은 접기·조건 변경·새 성공 응답에서 1위로 안전하게 복귀하는지 확인한다.
- 추천이 3개 이하일 때 버튼이 없는지 확인한다.
- 타입 검사, 린트, 전체 테스트, 프로덕션 빌드가 통과해야 한다.
