# 빠른 장소 선택 칩 제거 설계

## 목표

출발지·목적지 검색 입력 아래 표시되는 `코엑스`, `강남역`, `서울역`, `더현대 서울`, `국립극장` 빠른 선택 칩을 제거한다. 사용자는 네이버 API HUB 기반 자동검색 결과로 장소를 선택한다.

## 변경 범위

- `AppShell`의 출발지·목적지 `PlaceSearch`에 전달되는 빠른 장소 목록을 제거한다.
- 검색 입력, 디바운스, 실제 NAVER 결과 목록, 선택·초기화와 데모 폴백은 유지한다.
- 빠른 장소 데이터가 더 이상 런타임에서 필요하지 않으면 관련 import와 prop 전달을 정리한다.
- 다른 추천 조건과 지도 동작은 변경하지 않는다.

## 검증

- 렌더링된 플래너에 다섯 빠른 장소 버튼이 존재하지 않는다.
- `홍대입구역` 같은 임의 검색어의 결과 선택 흐름은 유지된다.
- 기존 AppShell·PlaceSearch 테스트, 타입 검사와 production build가 통과한다.

## 완료 조건

출발지와 목적지 검색 영역 모두 입력 아래 고정 장소 칩이 보이지 않고, 실제 검색 결과만 나타난다.
