# 추천 점수 UI 비노출 설계

## 목표

추천 카드 우측의 원형 숫자 점수(예: `73점`)를 사용자 화면에서 제거한다. 추천 계산과 정렬에 사용하는 내부 점수 데이터는 유지한다.

## 결정

- `ParkingRecommendation.score`와 `scoreBreakdown` 타입 및 계산 로직을 변경하지 않는다.
- `ParkingCard`에서 `.score` 버튼을 렌더링하지 않는다.
- 카드 헤더를 `순위 | 주차장 정보`의 2열 구조로 조정한다.
- 순위 선택 버튼, 카드 선택, 지도 연동, 추천 순서는 기존 동작을 유지한다.
- 기능 플래그나 CSS 전용 숨김 처리는 추가하지 않는다.

## 검증

- 실제 `ParkingCard` 렌더 테스트에서 점수 텍스트가 노출되지 않는지 확인한다.
- 기존 주차장명과 순위 UI가 계속 렌더링되는지 확인한다.
- 점수 계산 도메인 테스트는 변경하지 않는다.

## 범위 밖

- 추천 점수 산식 변경
- 추천 순위 변경
- API 응답에서 점수 제거
- 관리자용 점수 분석 화면 추가
